More Time-Pass Code Ideas

Want to practice coding games? Here are popular beginner-friendly time-pass game mechanics you can construct using HTML5 Canvas & Vanilla JS:

1. Classic Snake & Combo Apples

Easy

Control an array of coordinates `[{x, y}]`. On every tick, prepend a new head position and pop the tail unless an apple is eaten.

2. Brick Breaker (Breakout)

Medium

Uses basic circle-to-rectangle AABB bounding box collision checks to bounce the ball off paddle and 2D brick arrays.

3. Typing Speed Racer

Easy

Words drop down canvas or UI. User types matching keys to shoot down words. Calculate Net WPM = (Chars / 5) / Time.

4. Tower Stacker 2D

Medium

Moving blocks swing back and forth. Tap to drop block onto previous level. Trim overhang width based on misalignment!
